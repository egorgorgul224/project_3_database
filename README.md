## Описание<a id="description"></a>
Проект представляет собой изучение баз данных. В проекте создан класс HeadHunterApi для получения вакансий по
компаниям на сайте HeadHunter, модуль для создания базы данных, создания таблиц и заполнения таблиц данными
по компаниям и вакансиям, а также класс DBManager для подключения к базе данных и получения данных по sql-запросам.

## Методы и функции, примеры и тестирование<a id="func"></a>
### Методы, геттеры для класса HeadHunterApi
1. Метод *__init__* для инициализации экземпляра класса. Содержит следующие атрибуты:
* __url - ссылка на сайт
* __headers - шапка с данными для запроса
* per_page - количество страниц с вакансиями
* __params - параметры запроса и страниц
* __vacancies - список с вакансиями

2. Геттеры для вызова и получения данных из полей атрибутов. Список геттеров:
* url - ссылка на сайт
```
Вызов метода: 
return self.__url
```
* headers - шапка с данными для запроса
```
Вызов метода: 
return self.__headers
```
* params - параметры запроса и страниц
```
Вызов метода: 
return self.__params
```
* vacancies - список с вакансиями
```
Вызов метода: 
return self.__vacancies
```

3. Приватный метод *__api_connect* для подключения по API, возвращает json-данные через get-запрос. Для метода
реализован геттер *api_connect*.
```
Вызов метода: 
return self.__api_connect()
```

4. Метод *get_vacancies* возвращает список словарей с вакансиями по заданному ключевому слову(keyword).
```
Вызов метода: 
hh_api = HeadHunterApi()
# Получение вакансий по запросу
hh_vacancies = hh_api.get_vacancies(company_id, 5)
```

### Методы для класса DBManager
1. Метод *__init__* инициализации экземпляра класса DBManager. Содержит следующие атрибуты:
* conn - параметр с данными для подключения к базе данных
* cur - параметр для выполнения запросов
* company_table/vacancies_table - имена таблиц в базе данных

2. Метод *get_companies_and_vacancies_count*. Используется для вывода списка всех компаний и количество вакансий
у каждой компании.
```
Вызов метода: 
# Создание экземпляра класса для работы с запросами
db_manager = DBManager(params)
# Получение данных из базы данных
result = pd.DataFrame(db_manager.get_companies_and_vacancies_count())
print(result)
```

3. Метод *get_all_vacancies*. Используется для вывода списка всех вакансий с указанием названия компании, названия
вакансии и зарплаты и ссылки на вакансию.
```
Вызов метода: 
# Создание экземпляра класса для работы с запросами
db_manager = DBManager(params)
# Получение данных из базы данных
result = pd.DataFrame(db_manager.get_all_vacancies())
print(f"{pd.concat([result.head(5), result.tail(5)])}\n")
```

4. Метод *get_avg_salary*. Используется для вывода средней зарплаты по всем вакансиям.
```
Вызов метода: 
# Создание экземпляра класса для работы с запросами
db_manager = DBManager(params)
# Получение данных из базы данных
result = db_manager.get_avg_salary()
print(result)
```

5. Метод *get_vacancies_with_higher_salary*. Используется для вывода списка всех вакансий, у которых зарплата выше
средней по всем вакансиям.
```
Вызов метода: 
# Создание экземпляра класса для работы с запросами
db_manager = DBManager(params)
# Получение данных из базы данных
result = pd.DataFrame(db_manager.get_vacancies_with_higher_salary())
print(result)
```

6. Метод *get_vacancies_with_keyword*. Используется для вывода списка всех вакансий, в названии которых содержатся
переданные в метод слова.
```
Вызов метода: 
# Создание экземпляра класса для работы с запросами
db_manager = DBManager(params)
# Получение данных из базы данных
result = pd.DataFrame(db_manager.get_vacancies_with_keyword(word))
if result.empty:
    print("По вашему запросу не найдено вакансий")
else:
    print(result)
```

Вызов функции:

2. Функция *save_data_to_database* для заполнения таблиц данными.
```
Вызов функции:

```

через API с сайта HeadHunter, а также вывод пользователю данных по запросам.

Вызов main:
params = config()

    {"company_id": "58320", "company_name": "АО Россельхозбанк"},

    elif menu_item == "3":
        result = db_manager.get_avg_salary()
        print(f"{result}\n")
    elif menu_item == "4":
        result = pd.DataFrame(db_manager.get_vacancies_with_higher_salary())

    elif menu_item == "5":
        word = re.split(r"[,. ]+", input("Введите слово(а) для поиска вакансий: ").lower())
